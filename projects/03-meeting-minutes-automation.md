# 03 · Meeting Minutes Automation

**Structured Data → Word Document → Slack**

## 문제 정의
기업 미팅 후 회의록을 지정된 Word 양식에 맞춰 작성하고 Slack에 공유하는 과정에는 반복적인 문서 입력과 서식 조정이 필요했습니다. 이를 줄이기 위해 회의록 문서 생성 및 공유 과정을 자동화하는 도구를 구성했습니다.

## 실제 소스에서 확인된 기능
- JSON으로 정리된 회의 일시·참석자·목적 및 목차별 내용을 입력받는 구조
- 기존 DOCX 템플릿의 OOXML을 수정하여 문서 제목·표·주요 항목 자동 입력
- 파일명·출력 경로 지정과 문단·소제목 서식 구성
- Slack 봇을 이용한 메시지 게시, 스레드 댓글과 DOCX 파일 첨부 흐름
- 메시지 서식 변환과 링크 미리보기 제어

**사용 기술:** Python 3, JSON, OOXML/DOCX, Bash, curl, Slack Web API.

## 검증 및 한계
제공된 원본 ZIP의 스크립트와 입력 구조를 검토했으며, 예제 입력을 사용한 DOCX 생성 시험에서 문서 생성과 주요 섹션 입력을 확인했습니다. Slack 실제 전송이나 전사 루틴의 운영 안정성·업무시간 절감 효과는 별도로 검증되지 않았습니다.

이 프로젝트는 **전체 음성 전사 시스템이 아니라 회의 내용을 문서화하고 전달하는 부분**에 해당합니다.

**공개 범위:** 회사 원본 양식, 실제 회의 내용, 인증 토큰, Slack 채널 정보 및 내부 코드는 포함하지 않습니다.
