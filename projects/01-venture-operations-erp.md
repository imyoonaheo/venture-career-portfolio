# 01 · Venture Operations ERP

**Internal Workflow System · Data Structure · Web Development**

## 문제 정의
기업별 정보, 미팅 기록, 투자사 접촉 이력, 요청 자료와 후속 일정이 여러 곳에 분산되면 담당자는 현재 진행 상태를 파악하기 어렵습니다. 이러한 업무 흐름을 기업 중심으로 연결하는 ERP를 설계·개발하는 프로젝트입니다.

## 구현 코드에서 확인한 범위
- 기업·프로젝트 정보, 담당자, 진행 단계, 후속 액션 및 자료 관리
- 미팅 기록과 후속 할 일 연결, 기업별 파일 관리
- 투자사 접촉 이력과 TIPS/LIPS 매칭 관련 화면
- 기업 접수, 데모데이 평가 및 업무용 관리자 화면
- 사용자 역할별 접근 방식과 Supabase 기반 데이터 관리

**기술:** Next.js, React, TypeScript, Supabase, SQL.

## 접근 방식
실무에서 실제로 필요한 정보와 업무 순서를 정리하고, 기업별로 관련 데이터를 확인·수정할 수 있는 화면과 워크플로를 구성했습니다. 반복 점검에 필요한 구조를 마련하면서 투자 판단 자체는 담당자가 수행하도록 구분했습니다.

## 확인 범위
원본 저장소의 기능별 대표 코드를 확인했습니다. 일부 투자 딜 화면에는 목업 데이터가 있으며, 모든 기능의 실제 운영 여부나 정량적 개선 성과를 검증한 것은 아닙니다.

**공개 범위:** 회사 코드·기업 자료·실제 계정·연락처·업무 데이터는 재배포하지 않습니다.
